# P0 之后的真实数据暂缓清单

> 本文件记录“因缺少真实输入而暂不实施或验收”的事项。合成 P0 可以继续，以下条目不得因合成案例通过而勾选为正式完成。

| 暂缓事项 | 所需真实输入 | 责任方 | 当前阻塞原因 | 解除条件 |
|---|---|---|---|---|
| 负荷组九文件正式接收 | `01`～`09` 全套、版本和校验值 | 负荷组 | 尚无正式交付，字段中仍有待确认项 | 九文件只读落地；数据字典、源日志和问题回答齐全 |
| 正式接口准入结论 | 九文件及 QA 报告 | 代码组 | 不能对不存在的数据判断通过/拒绝 | 校验器运行后生成 `interface_acceptance.md` |
| 逐栋转换对账 | 正式建筑清单和逐时负荷 | 负荷组 + 代码组 | 无法核对 ID、峰值、累计量 | 生成逐栋 `load_reconciliation.csv`，误差在批准容差内 |
| 光谷 6～12 栋 / 168 小时调试 | 代表建筑、连续 168h、边界说明 | 项目技术负责人 | 当前只允许合成 smoke | 正式小样例通过校验、适配、求解和 QA |
| 光谷全园区和完整供暖季 | 全部有效建筑和完整供暖季负荷 | 项目技术负责人 + 负荷组 | 边界、季节和数据版本未冻结 | 小规模闭环通过，正式季节范围获确认 |
| 正式温度 COP/容量 Provider | 热泵性能曲线、外推边界、供回水温度和版本 | 设备性能负责人 | 当前只有接口和 V0 固定 COP Provider | Provider 覆盖全部技术×2160h，手算、边界和联合测试通过 |
| 自动候选站/道路候选管网 | 算法、道路约束、禁建规则、随机种子和参数版本 | GIS/规划负责人 | 当前只消费一个给定站点和给定物理管网 | `CandidateNetworkProvider` 交付，候选可追溯且与 Core 联合验收 |
| 真实道路/可建设空间 | 有许可的道路或用地约束、CRS、禁建属性 | GIS/规划负责人 | 当前无可施工 GIS 约束 | GIS 来源、许可、字段和贴靠规则确认 |
| 真实资源锚点 | 余热/污水/河湖位置、温度、逐时可用量 | 资源专业负责人 | 无资源位置和利用条件 | 项目组提供可追溯锚点和可用量；功能实现并升级契约 |
| 正式技术经济参数 | COP/效率、容量、投资、`[0,1]` 固定维护比例、`CNY/kWh_th` 可变运维、寿命、来源 | 技术经济负责人 | 不得从默认模板或合成值推断；附件未给可直接采用的维护数值 | 参数表、价格基年、单位和假设标记获批准 |
| 正式外部时序 | 气温、电价、LHV 气价、碳因子、资源可用量 | 能源经济/碳核算负责人 | 来源、版本和能源口径未确认；体积气价缺同体积基准 LHV | 与负荷同时间轴并通过条件列校验；气价只在边界转换一次 |
| 正式年度小时权重 | 每个时间点的 `time_weight_h_per_year` 与年度代表小时总和 | 项目技术负责人 | 合成权重只能验证公式，不能代表武汉年度 | 时段代表性、总小时数和供暖季边界签认并通过权重和校验 |
| 正式管网经济参数 | 管道单位长度投资、管道寿命及来源 | 管网/造价负责人 | 当前只有合成参数，不能从旧 EUR 模板推断 | `CNY/m`、寿命、价格基年和费用边界获批准 |
| 正式接入经济参数 | 每个需求节点的接入投资、寿命及来源 | 管网/造价负责人 | 接入年化是项目扩展，附件未给公式或数值 | 节点全集参数与公式经项目负责人签认 |
| 正式 HNS 罚值 | `CNY/kWh` 罚值、允许短缺边界和披露规则 | 经济/可靠性负责人 | 罚值影响优化但不是真实支出，当前仅有合成值 | 罚值与可靠性规则签认，结果单列真实成本和罚项 |
| S0～S3 正式比较 | 相同负荷、舒适标准、价格、规划边界 | 项目负责人 | 基础数据和扩展模型均未完成 | 各场景共用冻结边界且逐项通过 QA |
| Pareto 和敏感性 | 碳模型、正式参数范围和情景矩阵 | 项目负责人 + 碳核算负责人 | P2 能力及真实范围缺失 | 成本/碳分项可重算，参数范围获批准 |
| 武汉新城迁移 | 最终研究边界及上述全部正式输入 | 项目负责人 | 软件园试点尚未正式验收 | 软件园流程可复现并冻结最终数据版本 |

## 当前可以继续的工作

- 使用公开、极小且明确标记 `synthetic_test` 的 V1 legacy 4 栋 × 24 小时 fixture 或 V3 2 节点 × 24 小时 fixture；
- 实现七类标准输入的校验、适配和错误路径；
- 修复单位、时间、随机性、无余热、未供热平衡和 HiGHS 接口；
- 维护单命令 smoke、规范结果、自动测试和只读 V1.0 发布门。

这些工作只证明软件接口和计算闭环，不证明武汉真实方案、正式年度成本或工程可施工性。
