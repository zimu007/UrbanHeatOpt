## 2. 先独立验算再绘图

逐点检查输入版本、62建筑／2160小时、单位、时间顺序、唯一键、全部字段有限性和文件hash；未认证／未完成点不得进入“成功前沿”。分清52周／全年与冬季代表年运行量：2160h只含冬季，投资CRF按年摊销，不能把冬季电耗称8760h全年总电耗。

独立复算项目：

1. 初始设备容量×报价×CRF，固定／可变运维；管线路由长度×双管路由单价，不重复乘2；接入与支管不双算；TES功率／能量／固定费用边界。
2. 逐时用电×绝对电价×权重、燃气输入×LHV价格×权重；V2逐月同小时总电力最大值×42，不把逐楼各自峰值相加。
3. 电力间接碳排＋燃气直接燃烧，kgCO2e到tCO2e除1000；碳价另列，欠供热惩罚不混真实费用。
4. 所有节点／小时热平衡、设备低温能力、管段容量／未建零流、连通性、泵耗与热损；TES开启时首末SOC、效率损失、容量功率和互斥。
5. 前沿非支配、重复物理方案、端点及膝点规则；不因最终展示一个膝点删掉端点边界证据。

输出机器JSON＋中文QA。热平衡≤1e-6kW、费用／碳差≤1e-6（保留原单位后再展示四舍五入），其他容差使用SolveRequest配置并记录；未通过时图标红／不推荐，不静默修数据。

## 4. PPT级样式规范

- 主画布16:9；常用1600×900预览、3200×1800及以上PNG（建议300dpi），另交SVG／PDF矢量版。不是本轮制作PPT文件。
- 字体优先可用中文黑体／微软雅黑，缺字体明确提示并选择实际可用字体，不生成方框；在目标Windows机器实际检查。
- 模式固定配色：集中蓝、分布橙、混合绿；膝点紫／明确形状；同一颜色跨图语义一致。色盲友好、标记形状和线型并用，不仅靠红绿。
- 白底、少网格、标题结论清楚；PPT缩放后正文建议≥18pt、轴标≥16pt，单位随轴或列名，避免三维饼图和过度装饰。
- 每图脚注含数据版本、模型版本、point_id、时间范围、单位、优化限制；完整版元数据放图旁JSON，不把长SHA塞满画面。
- 接近的61/1与全集中差异同时显示绝对值和比例，说明误差／gap与参数不确定性，不用截断坐标制造巨大优势。
- GIS候选浅灰虚线、建设实色实线，建筑分类／图例／比例尺／CRS或底图来源清晰；地块未核实与已初筛区分。

## 5. 图册与实际渲染验收

建议输出：`figures/`、`tables/`、`qa/`、`figure_manifest.json`、`INDEX.md`。manifest至少记录figure_id、point_id、输入文件hash、代码GitSHA、过滤条件、单位转换、输出文件和渲染状态。

每张图必须打开PNG或PDF实际查看：是否空白、中文缺字、坐标截断、图例遮挡、单位错误、颜色混用；检查像素大小和数据series非空。不以文件存在或绘图退出0当验收。抽取源数据点手算核对柱高／曲线与图表相符。

单元测试用小型合成ResultBundle（显著synthetic），覆盖缺列、NaN、错误单位、未知point_id、失败QA、重复点和不存在结果文件。另对只读V1执行真实适配／复算；V2由B交付后跑同一套QA。不要对V1旧参数结果套新版价格后仍标V1。
